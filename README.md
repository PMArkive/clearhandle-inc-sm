# Description
Clear handles.

# Examples

### ArrayList
```sourcepawn
ArrayList list = new ArrayList();

ClearArray_Ex(list);
```

### ArrayStack
```sourcepawn
ArrayStack stack = new ArrayStack();

ClearStack_Ex(stack);
```

### StringMap
```sourcepawn
StringMap map = new StringMap();

ClearTrie_Ex(map);
```

### IntMap (https://github.com/Ilusion9/intmap-inc-sm)
```sourcepawn
IntMap map = new IntMap();

ClearTrie_Ex(view_as<StringMap>(map));
```
